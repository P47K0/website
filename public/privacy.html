Privacy Notice

Last updated: September 2026

This is a short, plain-language note about the little data this site collects. It's a personal portfolio site, not a product with accounts or user profiles — the goal here is to be upfront about what runs in the background, not to cover every legal contingency.

Cloudflare Web Analytics

The site uses Cloudflare Web Analytics, a privacy-respecting analytics beacon. It does not use cookies and does not track individuals across sites. It only reports aggregate traffic patterns (pages viewed, load times, general location by country).

Human visitor counter (Cloudflare Turnstile)

To show a rough count of real human visits without ever displaying a CAPTCHA, this site uses Cloudflare Turnstile in invisible mode. Turnstile runs a background check in your browser and never shows a puzzle or asks you to do anything. See Cloudflare's Turnstile Privacy Notice for details on what Turnstile itself processes.

If that check passes, and you've been on the page a few seconds and interacted with it in some ordinary way (scrolling, moving the mouse, etc.), the site records one entry: a one-way hash of your IP address and browser combined with the day and a secret value that changes daily. This means:

  • No cookies are set, and no raw IP address is stored.
  • The hash changes every day, so the same visitor can't be linked across different days.
  • The only thing kept is a running count — there is no way to reconstruct who visited from the stored data.

Contact form

If you use the contact form, the name, email address, subject, and message you submit are stored so the request can be answered, and an email notification is sent to Patrick. This data is only used to respond to you.

Questions

If you have questions about any of this, reach out via the contact page.

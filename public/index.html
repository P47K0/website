Cost-Conscious Architecture

Every side project starts from "what can the free tiers cover?" — Cloudflare's free plan for Workers, DNS and Web Analytics, Azure Cosmos DB's free tier as the data layer, Azure Container Apps on the Consumption plan scaling to zero when idle. Authentication is split between Microsoft Entra ID's free tier and Cloudflare Zero Trust (Access), the latter currently gating just the CKA Practice Lab. The AI demos lean on Cloudflare Workers AI's inexpensive models rather than Azure AI Foundry, for the same reason. Anything beyond that — like spinning up an AKS cluster via an Azure DevOps pipeline to test something or record a demo, then tearing it down again — runs on the monthly Azure credit included with my Visual Studio Professional subscription. Real infrastructure, near-zero standing cost.

My work style

How this actually gets built and kept up to date

Agentic backlog management

Ideas and the feature backlog live on a private GitHub Projects board. Claude Code files and updates items directly via the GitHub GraphQL API during planning conversations, capturing decisions and open questions as they're made.

See the public backlog →

Blog content pipeline

Posts are written as Markdown, stored in Cosmos DB, served through an ACA API. I ask Claude to insert or update articles directly; deleting a post is deliberately left to me only. A Cloudflare Worker converts Markdown to HTML on the way out.

Building this website

Started out built with Aider paired with a local Qwen2.5 model running via IPEX Ollama. Ongoing iteration — new sections, project cards, fixes — now runs through Claude Code instead.

Everyday tool stack

VS Code for frontend work, Visual Studio Pro for backends — the same split at work and on side projects.

Work: Azure Repos/DevOps/Registry, AKS
Side projects: GitHub Actions/Registry, ACA

Cost-conscious architecture

Every side project starts from "what can the free tiers cover" — Cloudflare Workers/DNS/Web Analytics, Cosmos DB free tier, Container Apps scaled to zero, Entra ID plus Cloudflare Zero Trust for auth. Workers AI over Azure AI Foundry for the same reason. Anything bigger runs briefly on the Azure credit from my VS Pro subscription, then gets torn down.
